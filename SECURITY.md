# Security policy

## Supported versions

Security fixes are made for the current production release of FindSpot V5 and the current FindSpot Companion beta. Please reproduce an issue against the latest published version where possible.

## Private reporting

Please use [GitHub private vulnerability reporting](https://github.com/Fenlanddavid/findspot/security/advisories/new). Do not include private FindSpot records, exact find coordinates, landowner information, photographs or unredacted backups unless they are essential and you have agreed a safe transfer method with the maintainer.

A useful report includes the affected version, entry point, expected and observed result, reproducible steps, impact, and a minimal redacted proof of concept.

Please allow reasonable time for validation and a coordinated fix before public disclosure. Receipt will be acknowledged when the report is reviewed; confirmed reporters may be credited in release notes if they wish. FindSpot does not currently operate a bug-bounty programme.
